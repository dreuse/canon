# Canon — identity kit v1.0
Mark: **Cited** — a quotation mark cut as two heavy wedges. A canon is the set of texts everyone quotes.

## Geometry
u = 1/10 of the mark height. Each wedge is 6u wide, 10u tall; its right edge drops at 42% of the
height and runs down to the full height on the left. The gap between wedges is 2u and never changes.
Clear space: 2u on all sides of the bounding box.

The lockup SVGs reference IBM Plex Sans (SIL Open Font License) as live text so you can edit the
name. Convert the text to outlines before sending artwork to a printer or vendor.

## Colour
ink     #2A2724   the mark, body text
paper   #F6F4F1   backgrounds
clay    #C2703F   interface accent only — never a wedge in the logo
stone   #C9C3B9   rules, muted UI

The logo is ink on paper or paper on ink. Nothing else.

## Type
IBM Plex Sans Medium (500), tracking -3.5% for the wordmark, -2.5% for headings.
Wordmark cap height : mark height = 1 : 0.85, aligned to the cap line.
Mark height in the horizontal lockup sits 2u from the wordmark.

## Minimum sizes
Bare mark: 16px tall. Below that the notch closes — use the rounded-square icon instead.
Print: 5mm tall.

## Don't
Rotate it. Widen the gap. Colour the two wedges differently. Add a shadow, outline or gradient.
Place it on a busy photograph without a solid ink or paper field behind it.
